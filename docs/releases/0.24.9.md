# Crowe Logic 0.24.9

Draft. The version bump, tag and publish happen in the release step on
Michael's word, after the design review has looked at the rooms flow. This
text is the release body for that step, in the shape 0.24.8 used.

Rooms edition. Carries everything on main since 0.24.8:

- Rooms are standing colleagues. The rail lists each room like an inbox: who is
  in it, the last thing said, an unread dot, and a mark that turns while a seat
  works. A room has a brief every seat carries, and routines that let it speak
  first: daily, weekdays, weekly or every N minutes, in local time, with a
  notification when it posts.
- Seats work out loud. What a seat says between tool rounds lands as short
  messages while it is still working; the last one is its reply.
- Seats ask instead of guessing. A seat can end its turn on one question with
  up to four options you answer in a tap; typing over the card works too. The
  choice is a message, not a permission: the tool gate still decides what may
  run.
- Messages can be carried into another room, where that room's seat answers
  them, attributed to who said it and where.
- Fix: an approval raised by a room seat had nowhere to be answered and was
  denied after five minutes. The room thread now draws the approval card under
  the seat that asked.
- Fix: a hand-configured MCP server's tools ran ungated from a read-only room.
  A room seat's call to such a tool now asks first unless the tool's name
  plainly says it only reads (get, list, search, analytics and the like). The
  name test is a heuristic and says so. The plain operator thread is unchanged.

Known limitations, stated in the app as well:

- Rooms run read-only until worktree isolation (Gate 4) lands. A room can
  find, report and ask; the action goes through an approval card or your hands.
- Routines run only while the app is running. There is no cloud machine
  behind a room; a laptop that slept through 07:00 runs the brief on waking if
  it is within two hours, and otherwise leaves a note.
- Real seats on real channel data are untested beyond the founder's own runs;
  every automated check uses a stubbed gateway.

Updates are served from https://releases.crowelogic.com/desktop/channel/<os>.
macOS builds are notarized and stapled on the release machine; the Windows
installer is unsigned (SmartScreen will show an unknown publisher).
