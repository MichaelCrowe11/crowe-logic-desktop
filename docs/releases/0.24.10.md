# Crowe Logic 0.24.10

Connectors and tools edition. Carries everything on main since 0.24.9:

- Channel Analytics: the first server bundled in the app. A read-only connector over the channel manager's state (snapshots, recent uploads, machine Shorts, hand tasks, daily brief, Stripe attribution). A room seat answers "morning snapshot" from it; the collector run sits behind the edit tier. The bundled server runs as a utility process so a packaged build can start it (PR 82).
- Messages rail: Rooms read as conversations with workers, with a New message contact picker, Add to conversation, and a Developers edition roster filter (PR 85).
- Worker marks: each worker wears one of the eight thinking marks as vector, animated only while it reasons, still under reduced motion (PR 92).
- generate_image: a picture from a prompt through the user's own image key, saved under assets/generated. Always asks before it spends (PR 86).
- share_preview: a temporary public link to what the agent built, a folder or a local port, with an expiry and a stop. Always asks (PR 90).
- Mail connector: send_email over SMTP as a built-in plugin, gated at Execute, always asks, and honest about "possibly sent" (PR 91).
- export_document: Markdown in, a PDF, HTML or Markdown file out under exports/, behind the same gates as a file write and the secret scanner (PR 88).
- The redaction shown on tool cards and approval cards names the kind of secret it removed, in brackets, and cuts a private key block from header to footer.

Updates are served from https://releases.crowelogic.com/desktop/channel/<os>. macOS builds are notarized and stapled on the release machine. The Windows installer is signed through Azure Trusted Signing; SmartScreen shows the publisher as Michael Crowe until an organisation validation is added.
