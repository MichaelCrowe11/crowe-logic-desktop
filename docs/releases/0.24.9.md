# Crowe Logic 0.24.9

Rooms edition. Carries everything on main since 0.24.8:

- Rooms are standing colleagues. The rail lists each room like an inbox: who is in it, the last thing said, an unread dot, and a mark that turns while a seat works. A room has a brief every seat carries, and routines that let it speak first: daily, weekdays, weekly or every N minutes, in local time, with a notification when it posts (PR 71).
- Seats work out loud. What a seat says between tool rounds lands as short messages while it is still working; the last one is its reply.
- Seats ask instead of guessing. A seat can end its turn on one question with up to four options you answer in a tap; typing over the card works too. The choice is a message, not a permission: the tool gate still decides what may run.
- Messages can be carried into another room, where that room's seat answers them, attributed to who said it and where.
- Activity: the panel beside the chat shows the agent's work as it happens, with a Follow mode that keeps up with it (PR 84).
- First run asks for a project folder instead of pointing the workspace at the home folder; the sign-in copy states that the free tier needs no card and no keys; your own terminal is no longer gated by the agent's tier (PR 87).
- Plugin servers start with the login shell's PATH, so the GitHub plugin works from a Finder launch, not only from a terminal (PR 83).
- Sign-in: a second click on Sign in joins the pending attempt instead of failing on the loopback ports (PR 89).
- run_shell: a line is treated as a cd only when it is nothing but a cd; `cd X && cmd` now runs in the shell (PR 93).
- Fix: an approval raised by a room seat had nowhere to be answered and was denied after five minutes. The room thread now draws the approval card under the seat that asked.
- Fix: a hand-configured MCP server's tools ran ungated from a read-only room. A room seat's call to such a tool now asks first unless the tool's name plainly says it only reads (get, list, search, analytics and the like). The name test is a heuristic and says so.
- Build: the phone bundle fails when the built page names a file the build did not copy (PR 94).

Known limitations, stated in the app as well:

- Rooms run read-only until worktree isolation lands. A room can find, report and ask; the action goes through an approval card or your hands.
- Routines run only while the app is running. A laptop that slept through 07:00 runs the brief on waking if it is within two hours, and otherwise leaves a note.
- Real seats on real channel data are untested beyond the founder's own runs; every automated check uses a stubbed gateway.

Merged after this cut and shipping in 0.24.10: the Channel Analytics connector, the Messages rail, the worker marks, generate_image, share_preview, the Mail connector and export_document.

Updates are served from https://releases.crowelogic.com/desktop/channel/<os>. macOS builds are notarized and stapled on the release machine. The Windows installer is signed through Azure Trusted Signing; SmartScreen shows the publisher as Michael Crowe until an organisation validation is added.
