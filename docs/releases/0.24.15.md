# Crowe Logic 0.24.15

The Master Brand Directive pass and the council's first run. Carries everything on main since 0.24.14:

- The app wears the directive. Light surfaces are Bone and Paper, dark surfaces Ink and Carbon, with Brass as the one signal color for the active control, the selected engine and the authority gate; status colors stay functional. Radii are 8 px or under, depth comes from 1 px rules instead of shadows, and there is no glass anywhere. Fraunces, Inter and JetBrains Mono remain the faces. Where the directive's Brass and Muted values fell under the app's enforced contrast gates, the text values were darkened and the reason is in the stylesheet (PR 122).
- The words follow the architecture. The tool permission tier reads as the operating envelope, with Plan, Read, Edit and Execute as the operating modes; the picker says Select engine; the gate authorizes; orchestrated multi-agent work is a mission and a single execution is a run. Config keys, IPC channels and the gateway API did not change (PR 122).
- The Gate Glyph is the app mark: a C jaw and an L jaw framing an aperture, with the brass core from the wordmark, on a Carbon tile. It is the macOS and Android icon and the standalone mark in the renderer; the wordmark itself is unchanged, and the iOS icon is untouched while 1.0 is in review (PR 122).
- Rooms gain a scoped council autopilot, model contacts and a voting interface. File authority for a council seat is the intersection of the roster and the room's operating envelope; receipts carry the record; the council can run on a headless host; a roster identity the registry cannot resolve fails the file grant closed (PR 121).

The app checks for updates at the releases worker, https://crowe-releases.yellow-block-3adc.workers.dev/desktop/channel/<os>, which also answers at https://releases.crowelogic.com/desktop/channel/<os>. macOS builds are notarized and stapled on the release machine. The Windows installer is signed through Azure Trusted Signing.
