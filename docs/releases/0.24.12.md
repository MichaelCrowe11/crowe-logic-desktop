# Crowe Logic 0.24.12

Console and mark edition. Carries everything on main since 0.24.11:

- Terminals are plain shells. Every terminal-backed panel, the agent console, the palette terminal, the dock launcher and the Agent Fleet cards, opens your login shell at its prompt and types nothing. Before, the agent console typed a command name into the shell as soon as it started, which on a clean machine began every session with "command not found". The objective dock still runs on the gateway agent. The panel head reads AGENT, without "CLI" (PR 96).
- A shell that fails to start is refused cleanly, with the reason printed in the panel, instead of a terminal left on "starting" (PR 96).
- The worker's mark follows the turn. While a turn runs, the mark rides beside the newest block, a tool card's rail dot or the first line of text, gliding there in 360 ms. When the turn lands, the flourish plays where the eye is and the mark goes home to the head of the turn. A tool-only turn lands beside the hint that replaces its cards. Under reduced motion there is no glide and the mark returns at once. An error or a stop clears it immediately (PRs 102, 105).
- For developers: a packaged build can be smoked on a throwaway profile with scripts/smoke-packaged-mac.sh, either a fresh unsigned build of the checkout or, with --app, an installed app or a release unzipped from the feed. The launch goes through Electron's --user-data-dir switch and never touches the live profile (PR 99).
- The releases worker gains an install counter: one Workers Analytics Engine data point per installer or update-feed request, by channel, platform and artifact kind. It deploys separately from the app; nothing in the app changed (PR 95).
- The 0.24.11 notes were corrected on Delivered/Read wording and the updater URL (PR 103).

The app checks for updates at the releases worker, https://crowe-releases.yellow-block-3adc.workers.dev/desktop/channel/<os>, which also answers at https://releases.crowelogic.com/desktop/channel/<os>. macOS builds are notarized and stapled on the release machine. The Windows installer is signed through Azure Trusted Signing; SmartScreen shows the publisher as Michael Crowe until an organisation validation is added.
